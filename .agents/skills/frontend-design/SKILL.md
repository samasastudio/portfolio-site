# Frontend Design & Visual Craft

This skill guides the creation of distinctive, production-grade frontend interfaces that avoid generic "AI slop" aesthetics. Implement real working code with exceptional attention to aesthetic details and creative choices.

## Design Thinking

Before coding, understand the context and commit to a **BOLD** aesthetic direction:
- **Purpose**: What problem does this interface solve? Who uses it?
- **Tone**: Pick an intentional aesthetic: editorial/magazine, brutalist/raw, retro-futuristic, luxury/refined, playful/toy-like, organic/natural, industrial/utilitarian, or clean neo-modernism.
- **Constraints**: Technical requirements (framework, performance, accessibility).
- **Differentiation**: What makes this **UNFORGETTABLE**? What's the one signature detail someone will remember?

**CRITICAL**: Choose a clear conceptual direction and execute it with precision. Bold maximalism and refined minimalism both work - the key is intentionality, not intensity.

Implement working code (React, Next.js, HTML/CSS, Tailwind) that is:
- Production-grade and fully functional
- Visually striking and memorable
- Cohesive with a clear aesthetic point-of-view
- Meticulously refined in typography, micro-interactions, and textures

---

## Frontend Aesthetics Guidelines

### 1. Typography
- Choose fonts that are distinctive and characterful. Avoid generic fallbacks like Arial, Inter, or basic system fonts for primary branding.
- Pair a distinctive display font with a refined body font. Use literary serif italics (`em`) or technical uppercase monospace labels (`font-mono uppercase tracking-widest`) to create typographic tension.

### 2. Color & Theme
- Commit to a cohesive palette using CSS variables.
- Dominant grounding colors with sharp, deliberate accents outperform timid, evenly-distributed palettes.

### 3. Motion & Micro-Interactions
- Focus on high-impact moments: one well-orchestrated entrance animation with staggered reveals (`animation-delay`) creates more delight than scattered random bounces.
- Use custom bezier easings (`cubic-bezier(0.16, 1, 0.3, 1)`), hover transforms with offset shadows (`hover:translate-x-1 hover:-translate-y-1`), and smooth state transitions.

### 4. Spatial Composition & Grids
- Use intentional layouts: asymmetric grids, editorial rails, overlapping cards, diagonal flows, and generous negative space or controlled information density.

### 5. Backgrounds & Textural Depth
- Create atmosphere and depth rather than defaulting to flat solid white or gray cards.
- Add contextual textures: subtle fractal noise overlays, gradient meshes, geometric patterns, layered transparencies, and tactile physical borders.

---

## What to AVOID (AI Slop Anti-Patterns)
- ❌ Cliched purple/violet gradients on white cards.
- ❌ Overused generic fonts (Inter, Roboto, Arial) without styling.
- ❌ Cookie-cutter dashboard templates that lack context-specific character.
- ❌ Uniform, unconsidered border radii on every single element.
